# 양세찬 게임 (Call My Name) 온라인 버전 — 설계 문서

## 배경

런닝맨에서 나온 "양세찬 게임"(콜 마이 네임)은 참가자마다 서로 다른 인물 이름이 이마에 붙고,
본인은 그 이름을 보지 못한 채 다른 사람에게 O/X 질문을 던져 자기 정답을 맞히는 파티 게임이다.
이 게임을 각자 스마트폰으로, 여러 명이 동시에 접속해서 플레이할 수 있는 웹 게임으로 만든다.

## 목표

- 링크 하나로 접속해서, 친구들과 각자 폰으로 동시에 플레이 가능
- 실제 게임처럼 "내 정답만 나만 못 보고 남들은 다 보이는" 상태를 화면으로 재현
- 이름을 직접 생각해내지 않아도, 난이도별 유명인 프리셋으로 바로 시작 가능
- 이름을 직접 정하고 싶은 그룹을 위한 직접입력 모드도 지원

## 비목표 (이번 범위에서 제외)

- 엄격한 턴(순서) 강제 — 실제 파티 게임처럼 자유롭게 아무나 질문/답변 (턴 타이머 없음)
- 음성/화상 통화 기능 — 같은 공간에 있다고 가정, 말은 실제로 하고 화면은 정답 확인용
- 회원가입/로그인 — 방 코드 + 닉네임만으로 참여
- 게임 기록 저장/랭킹

## 사용자 흐름

1. **방 만들기**: 누구나(host 개념 없음) 방을 만들면 방 코드 + 공유 링크 생성
   - 이름 모드 선택: **프리셋(기본값)** 또는 **직접입력**
   - 프리셋 선택 시 난이도(쉬움/보통/어려움) 선택
   - 인원 제한: 최소 2명 ~ 최대 8명 (기본값, 조정 가능)
2. **참가하기**: 링크로 들어와서 닉네임 입력 후 대기실 입장 (닉네임 중복 불가)
3. **정답 준비**
   - **프리셋 모드**: 별도 입력 없음. 인원이 2명 이상 모이면 아무나 "시작" 가능
   - **직접입력 모드, 2명**: 서로 상대방 몫 이름을 각자 1개씩 입력 (섞지 않고 그대로 상대에게 배정)
   - **직접입력 모드, 3명 이상**: 참가자 전원이 이름 후보를 1개 이상 제출 (실시간으로 제출 인원 표시) → 후보 개수가 참가 인원 이상이 되면 "시작" 가능
4. **이름 배정** ("시작" 누르는 순간 자동 처리)
   - 프리셋: 난이도 목록에서 중복 없이 랜덤으로 인원수만큼 뽑아 각자에게 배정
   - 직접입력 2명: 입력한 대로 그대로 상대에게 배정
   - 직접입력 3명 이상: 제출된 이름 풀을 랜덤 셔플 후 배정. 단, 자기가 낸 이름이 자기한테 배정되지 않도록 재배치(데레인지먼트) 처리
5. **게임 화면**
   - 목록 형태로 "닉네임 → 정답" 이 표시되는데, **내 줄만 목록에서 빠짐** (블러 처리가 아니라 아예 표시 안 함)
   - 실제로는 다 같은 공간에서 말로 질문/답변하며 진행 (앱은 정답 확인 용도)
   - 각자 다른 사람 줄 옆에 "맞았어요" 버튼이 있어서, 누군가 정답을 맞히면 그 사람 줄의 버튼을 다른 참가자가 눌러줌 → 그 사람 화면에 본인 정답이 공개되고 "완료" 표시
6. **완료 화면**: 전원이 맞히면 전체 정답 목록 공개하는 완료 화면 표시. "다시하기"로 같은 방에서 재시작 가능 (이름 재배정)

## 화면 목록

1. 시작 화면 (방 만들기 / 코드로 참가하기)
2. 방 설정 화면 (이름 모드, 난이도, 인원 제한)
3. 대기실 (참가자 목록, 닉네임 입력)
4. 이름 후보 제출 화면 (직접입력 3명 이상일 때만)
5. 게임 화면 (내 정답 제외 목록 + 맞았어요 버튼)
6. 완료 화면

## 데이터 모델 (Cloudflare D1 / SQLite)

- `rooms`: id(방코드), mode(preset/custom), difficulty(easy/medium/hard/null), max_players, status(waiting/submitting/playing/finished), created_at
- `players`: id, room_id, nickname, assigned_name(nullable), is_finished(bool), joined_at
- `name_submissions`: id, room_id, submitted_by_player_id, text (직접입력 3명 이상 모드에서만 사용)

닉네임은 방 안에서만 유일하면 됨. 플레이어는 브라우저 로컬 저장소에 자기 player_id를 저장해서,
새로고침해도 같은 참가자로 재접속 가능.

## 동기화 방식

여러 폰이 동시에 같은 방 상태를 봐야 하므로, 각 화면은 약 2초 간격으로 서버(D1)에서
방/참가자 상태를 다시 읽어와 갱신한다(폴링). 실시간 소켓 없이도 파티 게임 특성상
2초 지연은 문제되지 않음.

## 프리셋 이름 뱅크

"한국인이라면 누구나 알만한" 인물/캐릭터를 3단계로 구성 (각 티어 30개 이상, 최대 인원 8명 기준
중복 없이 뽑을 수 있는 여유 확보):

- **쉬움**: 매우 대중적인 연예인, 역사 위인, 국민 캐릭터 (예: 아이유, 손흥민, 세종대왕, 뽀로로)
- **보통**: 잘 알려졌지만 쉬움보다는 특정 관심사가 필요한 인물 (특정 배우/예능인/캐릭터)
- **어려움**: 팬덤/특정 세대에게 익숙한 인물 (매니아층 대상)

실제 목록은 구현 단계에서 작성.

## 예외 처리

- 방 코드 중복 시 재생성
- 닉네임 중복 시 입력 거부 및 재입력 안내
- 직접입력 모드에서 제출 인원 부족 시 "시작" 버튼 비활성화 + 안내 문구
- 새로고침해도 로컬 저장된 player_id로 같은 참가자로 복귀
- 인원이 2명 미만이 되면(중간 퇴장 등) 게임 진행 화면에 안내만 표시 (강제 종료는 하지 않음)
