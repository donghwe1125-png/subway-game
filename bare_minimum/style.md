# @bare_standard 카드뉴스 디자인 스타일 — BARE NOIR

**분위기 키워드**: 단호함 · 절제 · 신뢰

---

## 1. 색상 팔레트

| 용도 | 컬러 | 코드 |
|---|---|---|
| 배경 | 블랙 | `#000000` |
| 메인 텍스트 | 화이트 (font-weight 200) | `#FFFFFF` |
| 서브 텍스트 | 미드 그레이 | `#888888` |
| 강조 컬러 | 와인 레드 | `#8B1A1A` |
| 브랜드 표기 | 다크 그레이 | `#555555` |

---

## 2. 폰트

- 제목: 시스템 산세리프, `font-weight: 200~300`, 자간 약간 좁게 (`letter-spacing: -0.02em`)
- 본문: 동일 폰트 패밀리, `font-weight: 300`, 행간 넓게 (`line-height: 1.6`)
- `system-ui, -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif`

---

## 3. 레이아웃

- 좌측 정렬 기본, 헤드라인은 2~3줄로 끊어 임팩트 강조
- 상단 1/3 여백 → 중단에 헤드라인 집중 → 하단 브랜드 영역
- 여백(padding) 넉넉하게, 압축된 정보량

---

## 4. 카드 구성 요소

- 좌상단: 번호박스 (`01`, `02`…) — 와인레드 배경 + 화이트 숫자
- 중단: 대형 헤드라인 (한 문장 핵심 메시지)
- 헤드라인 아래: 서브텍스트 1~2줄 (그레이)
- 하단 좌측: `@bare_minimum` / 하단 우측: 슬라이드 번호 (`1/5`)

---
